# Media Preparation Notes

Before sharing the repository publicly, prepare a small media set:

## Recommended Assets

- `media/hero-desktop.png`
  A clean screenshot showing Mochi on the desktop with the companion bubble visible.

- `media/chat-panel.png`
  A screenshot of the chat panel with the soft product styling.

- `media/file-analysis.png`
  A screenshot that shows a document being analyzed and reflected back through the companion flow.

- `media/mochi-motion.gif`
  A short loop that shows idle motion, a tap reaction, and one context-aware bubble.

## Capture Guidance

- use a clean desktop background
- avoid cluttered taskbars or personal notifications
- keep the pet large enough to read clearly
- show the soft motion and bubble language, not just static UI
- avoid exposing local usernames, private chat titles, or sensitive file names

## README Placement

Suggested order:

1. hero screenshot near the top
2. short product description
3. current capabilities
4. motion GIF
5. development and build instructions
