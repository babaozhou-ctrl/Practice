# Luna 模板包

这是一个给社区作者使用的示例宠物包模板，不是最终内置宠物。

它的作用：

- 演示完整宠物包需要哪些文件
- 提供 `personality`、`companion-content`、`production` 的最小结构
- 让导入器和后续社区宠物包生态有一份可复制起点

当前说明：

- `sprite-atlas.png` 还没有随模板附带，这个目录默认处于 `hybrid` 阶段
- `sprite-definition.json` 只是 fallback 占位结构，方便运行时仍然能识别这个包
- 真正要对外分发时，建议替换为完整 atlas、contact sheet 和预览 gif
